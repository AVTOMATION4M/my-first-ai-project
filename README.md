# my-first-ai-project

Welcome to my first AI project. This repository is a space for learning and experimenting with modern AI tools, vibe coding, and automation.

## About This Repository

The goal is to build practical skills by working on small, hands-on projects. I use this repo to document experiments, test ideas, and track progress as I explore how AI can speed up development and automate everyday workflows.

Focus areas:

- **AI tools**: exploring and comparing modern AI assistants and platforms
- **Vibe coding**: building software through natural-language collaboration with AI
- **Automation**: creating workflows that save time and reduce manual work

## My Learning Goals

- Understand how leading AI tools work and when to use each one
- Get comfortable with vibe coding and turn ideas into working prototypes quickly
- Build automations that connect AI with real-world workflows
- Learn Git and GitHub fundamentals, including commits, branches, and documentation
- Publish small projects and share what I learn along the way

## Status

This project is in its early stages and will grow as I learn.
